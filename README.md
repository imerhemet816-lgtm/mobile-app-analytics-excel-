# Mobile App User Engagement & Campaign Performance Analysis

## Project Overview
An Excel-based data analytics project examining user engagement, marketing campaign performance, regional revenue, device activity, and cohort retention.

## Dataset
- 200 registered users
- 6 marketing campaigns
- 1,188 activity events

## Tools & Skills
Microsoft Excel, Data Cleaning, KPI Reporting, Cohort Analysis, User Behavior Analysis, Data Visualization.

## Business Objectives
- Analyze user activity and engagement levels.
- Compare Android and iOS users.
- Evaluate campaign and regional performance.
- Measure monthly cohort retention.
- Identify loyal users and revenue trends.

## Key Findings
- 11 users had at least three activity events in at least one calendar month.
- Revenue based on records marked Paid=True: $319,562.
- Campaign D generated $59,650 in recognized campaign revenue.
- North America generated $79,299.

## Workbook Structure
Overview, User Behavior, Campaign Results, Region Analysis, Region Campaigns, Cohort Retention, Device Analysis, Monthly Trends, Data Audit.

## Data Quality & Limitations
607 records contain nonzero payment amounts despite Paid=False; these amounts are excluded from recognized revenue. Some events occur outside campaign periods. Cohorts are based on first observed campaign activity rather than independently recorded enrollment dates.

## Business Recommendations
Investigate inconsistent payment records, review campaign activity dates, and test engagement strategies for lower-activity users.
